❌ 3. Validuješ veci, ktoré nemusia existovať
Problém:
form.trigger(['description', 'rules', 'scoringType', 'minWeight'])


Ale:

description je optional

rules je optional

scoringType má default

minWeight je jediný reálne kritický

👉 Ak sa niečo z toho pokazí, celý krok padne.

Odporúčané riešenie:
await form.trigger(['scoringType', 'minWeight']);


alebo:

await form.trigger();


(keď máš schema dobre spravené)

❌ 4. useEffect so sectorPlaces je nebezpečný

Toto je problém:

useEffect(() => {
  if (hasSectors && sectorPlaces.length !== numSectors) {
    setSectorPlaces(...)
  }
}, [hasSectors, numSectors, sectorPlaces.length])

❗ Problém:

meníš sectorPlaces

ktorý je v dependency array

čo môže spôsobiť nekonečný re-render

✅ Oprava:
useEffect(() => {
  if (!hasSectors) return;

  setSectorPlaces(prev => {
    if (prev.length === numSectors) return prev;
    return Array.from({ length: numSectors }, (_, i) => ({
      sectorName: `Sektor ${String.fromCharCode(65 + i)}`,
      places: Array.from({ length: 5 }, (_, j) => `Miesto ${j + 1}`)
    }));
  });
}, [hasSectors, numSectors]);
