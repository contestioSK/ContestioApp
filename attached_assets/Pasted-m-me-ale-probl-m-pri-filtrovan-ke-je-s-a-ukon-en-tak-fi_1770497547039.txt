Áno — “dnes / včera” je v ukončenej súťaži UX aj technicky zlé. Keď je event v minulosti, “dnes” už nemá s dátami nič spoločné, takže filter logicky „nefunguje“ (filtruje podľa dnešného reálneho dátumu, nie podľa dátumu súťaže).

Čo má byť správne správanie

Keď je súťaž ukončená (alebo keď si používateľ pozerá historické preteky), filter sa musí prepínať na absolútne dátumy súťaže, ideálne v časovej zóne súťaže.

Namiesto:

Dnes / Včera

Použi:

10.7. (Ne), 11.7. (Po), 12.7. (Ut) …
alebo ak chceš “game feel”:

Deň 1 (10.7.), Deň 2 (11.7.) …

Najčistejšie UX riešenie (odporúčam)

Filter = “Deň súťaže” (dropdown) + default “Všetky dni”.

Live súťaž: môžeš mať “Dnes / Včera” len ako skratky, ale stále nech sa pod tým mapujú na dátumy súťaže.

Finished súťaž: zobraz len dátumy (žiadne dnes/včera).

Technický koreň problému (prečo sa to deje)

const buildEventDays = (startISO, endISO) => {
  const days = [];
  const start = new Date(startISO);
  const end = new Date(endISO);
  // normalizuj na polnoc (pozor na timezone, ideálne robiť cez date-fns-tz)
  let d = new Date(start.getFullYear(), start.getMonth(), start.getDate());
  const last = new Date(end.getFullYear(), end.getMonth(), end.getDate());

  while (d <= last) {
    const key = d.toISOString().slice(0,10); // YYYY-MM-DD
    days.push({
      key,
      label: d.toLocaleDateString('sk-SK', { day:'numeric', month:'numeric' }), // 10.7.
      weekday: d.toLocaleDateString('sk-SK', { weekday:'short' }), // ne
    });
    d.setDate(d.getDate() + 1);
  }
  return days;
};
