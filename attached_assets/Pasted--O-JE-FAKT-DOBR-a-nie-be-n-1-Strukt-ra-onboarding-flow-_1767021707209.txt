ČO JE FAKT DOBRÉ (a nie bežné)
1️⃣ Struktúra onboarding flow

3 kroky = ideál pre MVP
Žiadny bullshit, žiadne prepaly.

Logická postupnosť:

identita → cieľ → spôsob konzumácie dát
To je UX textbook, máš to dobre.

2️⃣ Rozhodnutia sú produktovo použiteľné

Toto nie je „marketingový onboarding“.
Tieto dáta vieš reálne použiť:

routing (onSuccess redirect)

default UI preferencie

budúca personalizácia obsahu

➡️ Toto už je product-led onboarding, nie len welcome carousel.

3️⃣ UI komponenty

Cards sú jasné, klikateľné, čitateľné

Stav vybranej položky je:

border

bg

ring

check icon

➡️ Overkill? Áno.
➡️ Ale pre non-tech rybárov správne.

4️⃣ Optimistic update v React Query

Toto je už vyšší level, veľa MVP to nemá:

onMutate → cache update

rollback pri error

invalidate po settle

👏 Technicky chválim.

🟡 KDE TO ZAČÍNA DRHNÚŤ (dôležité!)
⚠️ 1️⃣ Onboarding je „príliš racionálny“

Používateľ necíti reward.

Teraz:

Vyber si → pokračuj → vyber si → pokračuj

Chýba:

„Prečo by som to mal vyplniť?“

„Čo z toho mám hneď teraz?“

KONKRÉTNE RIEŠENIE:

Do každého kroku 1 benefit sentence:

Step 1

„Podľa toho ti odporučíme vhodné súťaže a štatistiky.“

Step 2

„Contestio sa ti po dokončení prispôsobí.“

Step 3

„Uvidíš len to, čo ti reálne pomáha.“

➡️ +15 % completion rate bez zmeny logiky.

⚠️ 2️⃣ Skip onboarding = slabý fallback

Toto je najväčšia produktová chyba.

handleSkip() => onboardingCompleted: true


❌ Problém:

nemáš fishingStyle

nemáš mainGoal

routing ide defaultne?

UI nevie, čo preferovať

Správne MVP riešenie:

Ak skip → nastav default profil:

{
  fishingStyle: "carp",
  mainGoal: "diary",
  visualPreference: "lists",
  onboardingCompleted: true
}


➡️ Rybári nenávidia prázdne aplikácie.

⚠️ 3️⃣ Visual preference krok je UX slabší než zvyšok

Je to najmenej „hmatateľné“.

„Grafy vs zoznamy“ je abstraktné

user ešte nevidel dashboard

RIEŠENIE:

pridaj mini-preview screenshot / skeleton

alebo preformuluj otázku:

Namiesto:

„Ako najradšej sledujete progres?“

Použi:

„Ako chcete vidieť svoje výsledky?“

➡️ Jazyk rybára, nie produktového manažéra.

🔴 KRITICKÉ PRODUKTOVÉ RIZIKO
❗ 1️⃣ Nepracuješ s emóciou „OK, som dnu“

Chýba success moment.

Po kliknutí na „Dokončiť“:

žiadna gratulácia

žiadna mikro-animácia

rovno redirect

RIEŠENIE:

krátky success toast:

„Profil pripravený. Poďme na to 🎣“

Malá vec → veľký psychologický efekt.

🧠 STRATEGICKÉ ODPORÚČANIA (next level)
🧩 1️⃣ Zbieraj onboarding analytics

Minimálne:

step abandon rate

skip rate

completion time

Bez toho nevieš optimalizovať.

🧩 2️⃣ Onboarding ≠ jednorazový proces

Toto je initial setup, nie onboarding v plnom zmysle.

Chýba:

in-app nudges

contextual hints (po prvom úlovku, battle, grafe)

Ale to už je phase 2, nie MVP – takže OK.
