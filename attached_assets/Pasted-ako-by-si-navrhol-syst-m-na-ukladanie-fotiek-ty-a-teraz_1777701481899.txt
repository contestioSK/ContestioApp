GOLDEN RULE

👉 Upload nikdy nesmie byť závislý od backend procesu.

Backend nesmie:

držať image buffery

uploadovať na storage synchronne
držať queue v RAM

ROBUSTNÁ ARCHITEKTÚRA
1. STORAGE = S3 kompatibilné object storage

2. CLIENT UPLOAD → PRIAMO DO STORAGE

Toto je kritický bod.

Nie:

client → backend → storage

Ale:

client → storage

Backend iba vydá podpísaný upload URL.

Flow
Krok 1

Frontend:

POST /api/photos/presign

Backend:

vytvorí photoId
vygeneruje presigned upload URL
uloží draft záznam do DB

Vracia:

{
  "photoId": "...",
  "uploadUrl": "...",
  "publicUrl": "..."
}
Krok 2

Frontend uploadne fotku PRIAMO do storage.

Backend nič nebufferuje.

Žiadny RAM spike.
Žiadny Multer chaos.
Žiadny server bottleneck.
