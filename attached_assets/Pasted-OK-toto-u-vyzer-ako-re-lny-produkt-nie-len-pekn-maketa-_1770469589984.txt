1) Countdown je stále časová bomba (timezone + interval + “Prebieha”)

Teraz robíš:

Ak competition.startDate prichádza zo servera ako ISO bez timezone (alebo ako string typu 2026-02-07), prehliadače to interpretujú rôzne. Výsledok: odpočet môže byť posunutý o hodinu/dve (DST, locale parsing), a to je presne ten typ bugu, čo sa objaví u niekoho iného než u teba.

Fix (minimálny):

donúť backend posielať vždy plný ISO s timezone Z alebo offsetom.

alebo na FE vždy skladaj startAt z dátumu + času.

Patch: urob si helper getStartAt()
function getStartAt(dateISO: string, timeHHMM?: string) {
  // dateISO očakávaj ako ISO date alebo ISO datetime
  const d = new Date(dateISO);

  // ak už dateISO obsahuje čas (nie je midnight), nechaj tak
  if (!timeHHMM) return d;

  const [hh, mm] = timeHHMM.split(":").map(Number);
  // nastav lokálny čas organizátora (ak chcete, môžete to držať striktne v UTC)
  d.setHours(hh || 0, mm || 0, 0, 0);
  return d;
}
