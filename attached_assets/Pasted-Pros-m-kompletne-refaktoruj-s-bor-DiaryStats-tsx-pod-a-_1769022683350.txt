Prosím, kompletne refaktoruj súbor `DiaryStats.tsx` podľa nového konceptu "Contestio Stats 1.0".

Opúšťame starý dashboard s tabmi a prechádzame na jednotný "Magazín/HUD" layout, ktorý sa zameriava na storytelling a čisté dáta.

Kľúčové požiadavky na implementáciu:

1. Layout a Štruktúra (Responsive):
   - Mobile: Všetko v jednom vertikálnom stĺpci.
   - Desktop (md+): Grid layout (12 stĺpcov).
     - Ľavý hlavný stĺpec (8 cols): Sezónny prehľad, Hero Catch (veľká fotka), Mesačný trend.
     - Pravý bočný stĺpec (4 cols): Hodinový insight, Top druhy, Míľniky, Premium CTA.

2. Vizuálna Identita (CRITICAL):
   - Aplikuj farebnú paletu Contestia na nový layout.
   - Nahraď hardcoded HEX farby (napr. pozadia kariet, texty) za existujúce Tailwind triedy alebo CSS premenné používané v projekte (napr. `bg-background`, `bg-card`, `text-primary`, `border-border`), aby to ladilo so zvyškom aplikácie.
   - Zachovaj "Dark Mode" estetiku a taktický vzhľad HUDu.

3. UI/UX Zmeny:
   - Odstráň VŠETKY taby, filtre a komplexné nastavenia.
   - Implementuj kartu "Hero Catch", ktorá sa zobrazí len ak má úlovok fotku.
   - Vytvor ľahký CSS stĺpcový graf (TrendChart) namiesto externej knižnice.
   - Pridaj "Premium Teaser" (rozmazaný obsah) pre sekciu Hodinový Insight.

4. Kód:
   - Použi priložený kód ako základnú štruktúru komponentov a logiky.

Tu je referenčný kód nového dizajnu, ktorý treba implementovať a nastylovať podľa brandingu:

// 3. Mesačný graf (Bez osí, čistý trend)
const TrendChart = ({ data }: { data: {label: string, val: number}[] }) => {
    const max = Math.max(...data.map(d => d.val));
    return (
        <div className="mt-6">
            <div className="flex items-end justify-between h-24 gap-1">
                {data.map((d, i) => (
                    <div key={i} className="flex flex-col items-center flex-1 h-full justify-end group">
                         <div 
                            className={`w-full max-w-[12px] rounded-full transition-all duration-500 ${d.val > 0 ? 'bg-cyan-500' : 'bg-white/5'}`}
                            style={{ height: d.val > 0 ? `${(d.val / max) * 100}%` : '4px' }}
                         />
                    </div>
                ))}
            </div>
            {/* Osi mesiacov - Minimalistické */}
            <div className="flex justify-between mt-3 px-1">
                {data.filter((_, i) => i % 3 === 0).map((d, i) => (
                    <span key={i} className="text-[10px] text-slate-500 font-mono uppercase">{d.label}</span>
                ))}
            </div>
        </div>
    )
}
